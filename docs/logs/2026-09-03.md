## Three defects found
1. **The trial balance was never fiscal-year scoped** — my bug. The year filter
   sat on a `LEFT JOIN voucher` while `SUM` read `voucher_entry`, joined
   unconditionally, so every year was summed. Caught only by the A-10 cross-year
   reversal test the design insisted on. Fixed with `EXISTS`.
2. **`ServiceLoader` would have thrown at startup** — `accubook.module.api` had
   no `uses` clause, so `discover()` raises `ServiceConfigurationError` instead
   of returning empty. Latent (nothing calls it in production yet) but it is the
   intended startup path. P4 measured the empty case with an explicit provider
   list, which bypasses this.
3. **Stale-jar detour** — five tests failed against a not-yet-reinstalled
   `accubook-app`. Same class as the P1 `target/deps` incident. Verify artifact
   freshness before trusting a reproduction.
